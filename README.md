# Launchpad Mini 3 with M8

⚠️ ⚠️ ⚠️

THIS IS JUST A PERSONAL EXPERIMENT

Posting the code in case other people are curious.

This website will only work for my setup unless you happen to be using an M4 interface and the Launchpad Mini mk3.

⚠️ ⚠️ ⚠️

Th Dirtywave M8 has a way of working with the Launchpad Pro mk3 (which has hardware MIDI I/O) for clip launching. I was bored one Sunday and decided to try to make that work with my Launchpad Mini mk3 using an intermediary (a website running the Web MIDI API which is mostly just supported by Chrome).

So the M8 thinks it's talking to a LP Pro, but that's being simulated in the site.

The LP Mini thinks it's talking to a computer, but its messages are forwarded to the M8.
